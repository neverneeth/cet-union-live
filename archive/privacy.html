Privacy

This site was run by two students for the union election. It was not official. Here is what happened to what visitors sent while it was live, and what this archive does now.

Everything was deleted

The live site's servers were destroyed on 17 October 2026, and all the data they held was deleted with them: the exit-poll totals and the "already answered" list, noticeboard posts, comments and reports, the cooldown records, the admin accounts and the server logs.

The organisers kept a private offline copy of the vote-count entries and the admins' activity log, to check the count against. It contains no exit-poll answers.

What this archive contains

Only what the live site already showed publicly: the final count and the exit-poll totals. Where a count could not be confirmed, the archive shows the winner without figures. The archive sets no cookies, runs no analytics and loads nothing from other sites. Your light or dark theme choice is saved in your own browser and never sent anywhere.

The archive is hosted on GitHub Pages. GitHub, as the host, receives visitors' IP addresses under its own privacy statement.

Your university ID

When someone typed their ID into the exit poll or noticeboard, their phone checked its format and turned it into a scrambled code (a SHA-256 hash). Only that code was sent. The ID itself never left the phone.

Student IDs follow a known pattern, so someone with access to the server could, in principle, have worked out which ID produced a code by trying every possible ID. The system was designed so that this would not tell them anything useful:

  • Exit-poll answers were never stored as individual responses. Each answer only added 1 to running totals (for example, "Chairperson, candidate A, Civil, 2nd year"). There was never a row saying "this person voted for this candidate".
  • The code from an ID was stored only in a separate "already answered" list, re-scrambled with a secret key, with no answers attached.
  • The poll, posts and reports each used a different secret key, so the same ID could not be matched across them.

Breakdowns by programme and year

Exit-poll results were shown by programme and by year only when at least 5 people in that group answered. Smaller groups were hidden so nobody could be singled out. The archive keeps that rule.

Noticeboard posts

Posts and comments were stored without the poster's ID, name or any code linked to it, with times rounded to the minute. A post-cooldown record existed for about 10 minutes after each post and then deleted itself. The noticeboard is not part of this archive.

IP addresses

The site's code never logged IP addresses. The hosting provider's firewall (AWS WAF) saw them briefly so it could slow down anyone sending hundreds of requests. The optional "verify you are human" check was never switched on, so no other company saw them.

What the site could not promise

  • The exit poll was whoever chose to answer. It was not a scientific sample, and determined people could have tried to game it. Treat it as a rough signal.
  • The live count was typed in by hand from what was announced. The returning officer's figures are final.

The code is public

The code for the live site and this archive is public on GitHub.
